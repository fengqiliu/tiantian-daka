# 天天小达人 🌟

> 小学生 1-5 年级每日学习 / 运动 / 娱乐打卡微信小程序（上海小学版）
> 语文 · 数学 · 英语 + 跳绳户外 + 非屏幕娱乐，任务按年级自动生成，坚持看得见。
> 当前功能版本 **v0.18.0**：在打卡闭环之上，已有练习（跟读 / 口算 / 小卷 / 古诗）、错题间隔复习、奖励小铺、家长报告与周报、家长鼓励留言；版本详情见 [CHANGELOG.md](CHANGELOG.md)。

## 当前状态

- **本地功能已实现**：每日任务、打卡激励、日历、跟读、口算、小卷、古诗、错题本与间隔复习、任务管理、奖励小铺、家长报告与周报、数据备份恢复。
- **云端代码已实现，需部署验证**：多设备同步、家人绑定与家长只读视图、家长鼓励留言、每日提醒与里程碑通知、一键清空云端。当前 `utils/cloud.js` 的 `CLOUD_ENV` 为空，默认以纯本地模式运行。
- **测试资产**：124 项客户端逻辑用例、47 项云函数用例，均无需安装依赖。云函数测试使用内存数据库桩，不能替代真实微信云环境与双手机联调。
- **试用阶段**：按 [7 天真机试用指南](docs/trial-guide.md) 验证孩子与家长端流程，收集内容和交互反馈。

## 功能一览

**孩子端**

- **每日清单自动生成**：按年级（1-5）+ 日期确定性生成，上学日 4 项必做（语数英 + 跳绳），周末户外升级必做；古诗 / 单词 / 日记等按星期轮换
- **假期模式**：内置上海校历，寒暑假自动切换模板（假期作业必做、阅读与户外加量、口算减量、取消整理书包）
- **上海对齐**：沪教版课程语境、"双减"（低年级无书面任务）、近视防控（户外 / 屏幕限时 + 家长确认）、睡眠管理、跳绳体测项目
- **打卡闭环**：数值输入 + 星级自评（1-3⭐）+ 一句话记录 + 取消打卡；屏幕时间需家长确认
- **激励体系**：星星、5 级称号、18 枚勋章（打卡类 + 练习类）、连续打卡（今天未打不打断连击）；只和昨天的自己比，没有排行榜
- **学习练习**：英语逐句录音跟读、分级口算挑战、每周一卷（判断 / 选择 / 多选，等第制评价）、古诗背诵库
- **错题间隔复习**：口算与小卷错题按 1 / 3 / 7 天排期，连对 3 次才移出错题本；首页「今日错题复习」每组 5 题，累计复习 7 天得「错题克星」勋章
- **奖励小铺**：打卡赚积分、兑换家长上架的奖品；花积分不减少星星和称号
- **回顾**：月历热力图（达成 / 有打卡 / 未打卡）、单日明细、月度统计、本周各板块分布

**家长端**（家长用自己的微信绑定孩子，需云开发）

- **只读孩子视图**：今日进度、本周达成条、勋章、日历、错题本（含复习进度）
- **家长报告与周报**：周报默认看上周、可翻页（打卡与达成天数及对比前一周、练习概况、最多 3 条亮点与 3 条需关注，含"反复错的题型"）；另有近 7 / 30 天任务完成率、口算正确率趋势与小卷记录；家长首页显示上周周报摘要
- **鼓励留言**：给孩子发一句鼓励（常用语一键填 / 自定义 ≤40 字，可为某次已完成的打卡点赞），孩子首页弹出「妈妈说」卡片，家长可见已读；自定义文字经微信内容安全检查，每位家长每天最多 10 条
- **任务管理与奖品管理**（在孩子手机的「我的」页）：调整目标值、添加自定义任务；上架奖品与撤销兑换。改动自动同步到云端
- **里程碑通知**：孩子获得勋章时通过订阅消息通知家长

**数据自主**

- 未接入云开发时所有数据只存本机；接入后同步到云端，仅自己与绑定的家人可见
- 「我的 → 数据」：JSON 导出到剪贴板、从剪贴板导入恢复；一键清空（开通云开发后先清云端、成功后再清本机）

## 快速开始（微信开发者工具）

1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（Stable 版）
2. 打开工具 → 导入项目 → 选择本目录 `tiantian-daka`
3. AppID 选择 **"测试号"** 或自己的 AppID（`project.config.json` 中已配置作者的 AppID；fork 后请替换为自己的）
4. 编译运行：首次进入引导页选择身份、设置年级昵称，即可开始打卡
5. 运行测试（只需 Node，无需安装任何依赖）：

```bash
node test/run-tests.js           # 客户端逻辑（124 项）
node test/run-cloud-tests.js     # 云函数（47 项，含 openid 隔离、订阅配额、内容安全）
node scripts/sync-cloud-libs.js --check   # 校验云函数 lib 与 utils/ 是否漂移
```

## 云开发接入指南（多设备同步 / 家长端 / 提醒）

不接入云开发，小程序以**纯本地模式**完整运行（打卡、练习、复习、小铺、报告全部可用）。完成下面的配置、部署与验证后可使用：

- **多设备同步**：打卡记录、资料、勋章、任务覆盖、奖励小铺、练习记录（口算会话 / 小卷历史 / 复习日志）、错题本。跟读录音只存本机，不上云
- **家长端**：孩子生成 6 位邀请码 → 家长用自己的微信输入绑定 → 家长首页只读查看孩子进度、报告与错题本，并可发鼓励留言；孩子获得勋章时订阅消息通知家长
- **每日提醒**：每天 20:00（`cloudfunctions/dailyRemind/config.json` 的定时触发器），当天还有任务没打卡时发订阅消息（全部完成则不打扰）

配置与部署步骤：

0. 前置：**测试号（touristappid）不支持云开发**——需在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册自己的小程序（个人主体免费），拿到 AppID 并替换 `project.config.json` 中的 `appid`
1. 开通：开发者工具 → 云开发 → 开通，创建环境，复制**环境 ID**
2. 配置环境 ID：编辑 `utils/cloud.js` 顶部 `CLOUD_ENV`
3. 同步共享逻辑：`node scripts/sync-cloud-libs.js`（把 `utils/` 中的共享文件复制到 `dailyRemind/lib`、`sync/lib`、`family/lib`）
4. 部署函数：右键 `cloudfunctions/` 下 5 个函数（login / sync / family / remind / dailyRemind）→「上传并部署：云端安装依赖」。`family/config.json` 声明了 `subscribeMessage.send` 与 `security.msgSecCheck` 两项 openapi 权限，随函数一起上传
5. 数据库（控制台 → 数据库）：任意用户登录一次后 `users` / `checkins` / `badges` / `families` / `cheers` 会自动创建。`cheers` 只经云函数读写，权限建议设为「所有用户不可读写」。按 [data-model 文档](docs/data-model.md) 建组合索引：`checkins` 的 `(openid, updatedAt)`、`(openid, date)`；`cheers` 的 `(ownerOpenid, createdAt)`、`(fromOpenid, createdAt)`
6. 申请订阅消息模板：mp.weixin.qq.com → 订阅消息 → 选用"打卡提醒"类模板（含两个"事物"字段）→ 把提醒模板 ID 填入 `cloudfunctions/remind/config.js` 与 `cloudfunctions/dailyRemind/config.js`（两处必须是**同一个**模板 ID，否则订阅成功但定时任务发不出消息），把家长通知模板 ID 填入 `cloudfunctions/family/config.js`；字段名不同则同步修改对应 `index.js` 的 `data` 字段
7. 真机验证（两部手机）：孩子端「我的 → 家人绑定」显示邀请码 → 家长手机输入绑定；孩子打卡后家长首页应看到进度；家长发一条留言，孩子首页应出现「妈妈说」卡片；孩子端点「开启提醒」授权一次，当晚 20:00 未完成时应收到消息

> 以后修改了 `utils/tasks.js`、`utils/history-merge.js`、`utils/cheer.js` 等共享文件，都要重新运行第 3 步并重新上传对应云函数；提交前用 `--check` 确认无漂移。

## 技术说明

- 客户端采用纯原生小程序框架，无第三方 UI 依赖，使用 emoji 图标；云函数部署需要云端安装 `wx-server-sdk` 等各函数声明的依赖
- 核心逻辑全部收敛在 `utils/`（CommonJS），与页面解耦，因此可以脱离微信环境用 Node 做单元测试（含同步引擎的增量 / 冲突合并测试）；需要在客户端与云函数两边运行的逻辑放在无依赖的共享文件里，由 `scripts/sync-cloud-libs.js` 复制，测试会校验两边一致
- **本地优先（offline-first）**：读写永远走本地，云端是异步备份与跨设备通道；未配置云环境时全部云调用静默降级，UI 不出现不可用状态
- **数据作用域**：页面统一从 `utils/context.js` 的 `scope()` 取数——孩子端读本机，家长端读云端拉下来的孩子数据缓存（只读）
- **同步协议**（按数据形态选择合并规则）：
  - 打卡记录按 `id = date#taskId` 幂等，删除用墓碑（`deleted: true`）双向传播，冲突按 `updatedAt` 新者胜；增量游标以云函数返回的服务器时间为上限，防设备时钟漂移丢数据
  - 勋章只增不删，取并集
  - 资料、任务覆盖（`users.taskOverrides`）、奖励小铺（`users.shop`）、错题本（`users.wrongBook`）会被原地修改，整体按时间戳**新者胜**；写入时间戳严格递增（同毫秒连续操作也生效）
  - 口算会话与小卷历史是只追加列表，按完成时间 `at` **取并集**（`users.practice`）；复习日志每天一条，按日期合并、同日取次数多的一份
- **一键清空**：先调 `sync` 云函数的 `reset` 清云端（打卡、勋章、同步字段、收到的留言；保留用户档案、提醒配额与家人绑定），成功后才清本机，避免"本机清了、云端数据又同步回来"
- 星星口径：总星数 = Σ任务星级 + 每日全必做加成 1 星 + Σ已获勋章奖励星；全量动态计算，不冗余存储
- 订阅消息采用**配额模式**：用户每次授权累计 1 次可发送额度（上限 3），定时任务 / 里程碑触发时消费额度，43101（未订阅）自动清零
- **云函数安全**：openid 一律取自调用上下文，绝不信任前端传入；家长端只读孩子数据、留言不回传对方 openid；家长留言的自定义文字经 `security.msgSecCheck`，结果非通过或审核不可用时拒绝发送（读者是孩子）
