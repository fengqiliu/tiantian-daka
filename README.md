# 天天小达人 🌟

[![test](https://github.com/fengqiliu/tiantian-daka/actions/workflows/test.yml/badge.svg)](https://github.com/fengqiliu/tiantian-daka/actions/workflows/test.yml)

> 小学生 1-5 年级每日学习 / 运动 / 娱乐打卡微信小程序（上海小学版）
> 语文 · 数学 · 英语 + 跳绳户外 + 非屏幕娱乐，任务按年级自动生成，坚持看得见。
> 当前功能版本 **v0.34.0**：在打卡闭环之上（含计时打卡与家长确认的补打卡），已有练习（跟读 / 口算 / 小卷 / 古诗 / 记忆卡，一年级上册内容按单元收齐）、错题解析与间隔复习、单元星图与期末冲刺、每周小目标、奖励小铺、家长报告与周报、学期成长报告、家长鼓励留言；版本详情见 [CHANGELOG.md](CHANGELOG.md)。

## 功能一览

**孩子端**

- **每日清单自动生成**：按年级（1-5）+ 日期确定性生成，上学日 4 项必做（语数英 + 跳绳），周末户外升级必做；古诗 / 单词 / 日记等按星期轮换；一年级放假前 3 周多一项自选「期末冲刺」
- **假期模式**：内置上海校历，寒暑假自动切换模板（假期作业必做、阅读与户外加量、口算减量、取消整理书包）
- **上海对齐**：沪教版课程语境、"双减"（低年级无书面任务）、近视防控（户外 / 屏幕限时 + 家长确认）、睡眠管理、跳绳体测项目
- **打卡闭环**：数值输入 + 星级自评（1-3⭐）+ 一句话记录 + 取消打卡；屏幕时间需家长确认
- **计时打卡**：阅读、户外、练字、兴趣等时长类任务可点「开始计时」，倒计时到目标时长震动提醒，结束后自动填入分钟数；按开始时间推算，切后台、锁屏都不丢时间，首页显示进行中的计时
- **补打卡**：忘了打卡时，在日历里点昨天或前天补上（每周最多 2 天，需家长在孩子手机上确认）；补卡每项 1⭐、能接上连击，日历标「补」
- **激励体系**：星星、5 级称号、19 枚勋章（打卡类 + 练习类）、连续打卡（今天未打不打断连击）；只和昨天的自己比，没有排行榜
- **单元星图**：成长页列出每科全册单元，小卷练得越多越准点亮越多星（0-3 颗），点单元直接练；一科全部 2 颗星得「单元点灯人」勋章
- **学习练习**：
  - 英语跟读教室：一上 Unit 1-6 分单元逐句录音，默认接着上次的单元；另有单元卷「听力原文」加练（家长读、孩子跟录，不计入打卡句数）
  - 口算挑战：沪教版进度分级（含 20以内进位加 / 不退位减），一年级按学期月份推荐级别；答错显示凑十 / 破十方法提示
  - 每周一卷：判断 / 选择 / 多选，可按单元或「期末」练，等第制评价；答错说一句「为什么」（比大小先算再比、读音分平翘舌 / 前后鼻 / 声调）
  - 期末冲刺卷：全册每个单元都抽到，错得多的单元多练，做完看各单元掌握；一年级放假前 3 周首页倒计时，做完自动打卡
  - 今日一练（一年级）：首页一张卡片，3 题口算 + 5 题小卷约 3 分钟，其中 2 题来自最薄弱的单元，其余按星期轮换科目；解决"不知道练什么"
  - 古诗背诵库
  - 记忆卡：语文生字（第 1/5/6/7/8 单元）与英语单词（U2-U6）翻卡自测，连续认识 2 次即掌握，未掌握的下次优先出现
- **错题间隔复习**：口算与小卷错题按 1 / 3 / 7 天排期，连对 3 次才移出错题本；首页「今日错题复习」每组 5 题，累计复习 7 天得「错题克星」勋章；错题本里可按科目、只看到期筛选，小卷错题按「科目 · 单元」分组可只练一组，也可一键复制成文字（题目 + 答案 + 解析）粘贴到文档打印
- **每周小目标**：孩子每周自己选一个目标（5 天完成全部必做 / 跳绳累计 / 课外阅读累计 / 错题复习 3 天，累计量按年级定），首页进度条，达成 +5⭐；达成前可以换，达成后锁定
- **奖励小铺**：打卡赚积分、兑换家长上架的奖品；花积分不减少星星和称号
- **回顾**：月历热力图（达成 / 有打卡 / 未打卡）、单日明细、月度统计、本周各板块分布
- **学期成长报告**：按上海校历划分学期与寒暑假，可前后翻看：打卡 / 达成天数、最长连续、跳绳 / 阅读 / 户外 / 口算 / 古诗累计、新勋章、周目标达成数、口算正确率前后对比、本学期各单元掌握与期末冲刺次数（成长页进入，家长端也能看）

**家长端**（家长用自己的微信绑定孩子，需云开发）

- **只读孩子视图**：今日进度、本周达成条、孩子的本周目标进度、勋章、日历、错题本（含复习进度）
- **家长报告与周报**：周报默认看上周、可翻页（打卡与达成天数及对比前一周、练习概况、孩子的周目标进度、最多 3 条亮点与 3 条需关注，含"反复错的题型"和本周最薄弱的单元）；另有近 7 / 30 天任务完成率、口算正确率趋势、小卷记录与各单元掌握情况（孩子手机上点「再练练」的单元直接练）；家长首页显示上周周报摘要
- **鼓励留言**：给孩子发一句鼓励（常用语一键填 / 自定义 ≤40 字，可为某次已完成的打卡点赞），孩子首页弹出「妈妈说」卡片，孩子点一个表情回复（❤️😊💪🤗👍，不打字），家长在首页和已发出列表看到回复与已读；自定义文字经微信内容安全检查，每位家长每天最多 10 条
- **任务管理与奖品管理**（在孩子手机的「我的」页）：调整目标值、添加自定义任务；上架奖品与撤销兑换。改动自动同步到云端
- **里程碑与周报推送**：孩子获得勋章时通过订阅消息通知家长；家长可订阅每周一早上 08:00 推送的上周周报摘要（有薄弱单元时带上「再练…」）

**数据自主**

- 未接入云开发时所有数据只存本机；接入后同步到云端，仅自己与绑定的家人可见
- 「我的 → 数据」：JSON 导出到剪贴板、从剪贴板导入恢复（取消导入不会改动本机数据）；记忆卡进度目前只存本机，不在备份里；一键清空（开通云开发后先清云端、成功后再清本机）

## 快速开始（微信开发者工具）

1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（Stable 版）
2. 打开工具 → 导入项目 → 选择本目录 `tiantian-daka`（工具里项目名显示为「天天小达人」，名称与描述见 `project.config.json`）
3. AppID 选择 **"测试号"** 或自己的 AppID（`project.config.json` 中已配置作者的 AppID；fork 后请替换为自己的）
4. 编译运行：首次进入引导页选择身份、设置年级昵称，即可开始打卡
5. 真机试用：工具栏「预览」→ 用手机微信扫码。上传包约 390KB（试卷 PDF、测试、文档等已在 `packOptions.ignore` 里排除，远低于主包 2MB 上限），真机试用流程见[试用指南](docs/trial-guide.md)
6. 运行测试（只需 Node 18+，无需安装任何依赖）：

```bash
node scripts/run-all.js          # 一键跑下面全部检查（CI 也用它）
```

## 云开发接入指南（多设备同步 / 家长端 / 提醒）

不接入云开发，小程序以**纯本地模式**完整运行（打卡、练习、复习、小铺、报告全部可用）。完成下面的配置、部署与验证后可使用：

- **多设备同步**：打卡记录、资料、勋章、任务覆盖、奖励小铺、练习记录（口算会话 / 小卷历史 / 复习日志）、每周小目标、错题本。跟读录音只存本机，不上云
- **家长端**：孩子生成 6 位邀请码 → 家长用自己的微信输入绑定 → 家长首页只读查看孩子进度、报告与错题本，并可发鼓励留言；孩子获得勋章时订阅消息通知家长
- **每日提醒**：每天 20:00（`cloudfunctions/dailyRemind/config.json` 的定时触发器），当天还有任务没打卡时发订阅消息（全部完成则不打扰）

配置与部署步骤：

0. 前置：**测试号（touristappid）不支持云开发**——需在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册自己的小程序（个人主体免费），拿到 AppID 并替换 `project.config.json` 中的 `appid`
1. 开通：开发者工具 → 云开发 → 开通，创建环境，复制**环境 ID**
2. 配置环境 ID：编辑 `utils/cloud.js` 顶部 `CLOUD_ENV`
3. 同步共享逻辑：`node scripts/sync-cloud-libs.js`（把 `utils/` 中的共享文件复制到 `dailyRemind/lib`、`sync/lib`、`family/lib`、`weeklyReport/lib`）
4. 部署函数：右键 `cloudfunctions/` 下 6 个函数（login / sync / family / remind / dailyRemind / weeklyReport）→「上传并部署：云端安装依赖」。`family/config.json` 声明了 `subscribeMessage.send` 与 `security.msgSecCheck` 两项 openapi 权限，随函数一起上传
5. 数据库（控制台 → 数据库）：任意用户登录一次后 `users` / `checkins` / `badges` / `families` / `cheers` 会自动创建。`cheers` 只经云函数读写，权限建议设为「所有用户不可读写」。按 [data-model 文档](docs/data-model.md) 建组合索引：`checkins` 的 `(openid, updatedAt)`、`(openid, date)`；`cheers` 的 `(ownerOpenid, createdAt)`、`(fromOpenid, createdAt)`
6. 申请订阅消息模板：mp.weixin.qq.com → 订阅消息 → 选用"打卡提醒"类模板（含两个"事物"字段）→ 把提醒模板 ID 填入 `cloudfunctions/remind/config.js` 与 `cloudfunctions/dailyRemind/config.js`（两处必须是**同一个**模板 ID，否则订阅成功但定时任务发不出消息），把家长通知模板 ID 填入 `cloudfunctions/family/config.js` 的 `NOTIFY_TEMPLATE_ID`；周报模板 ID 同时填入 `cloudfunctions/family/config.js` 与 `cloudfunctions/weeklyReport/config.js` 的 `WEEKLY_TEMPLATE_ID`（两处必须相同）；字段名不同则同步修改对应 `index.js` 的 `data` 字段
7. 真机验证（两部手机）：孩子端「我的 → 家人绑定」显示邀请码 → 家长手机输入绑定；孩子打卡后家长首页应看到进度；家长发一条留言，孩子首页应出现「妈妈说」卡片；孩子端点「开启提醒」授权一次，当晚 20:00 未完成时应收到消息

> 以后修改了 `utils/tasks.js`、`utils/history-merge.js`、`utils/cheer.js`、`utils/week-brief.js`、`utils/subjects.js` 等共享文件，都要重新运行第 3 步并重新上传对应云函数；提交前用 `--check` 确认无漂移。

## 参与开发

本仓库的每个版本都按同一套流程交付，改动前请先读一遍：

1. **先写失败的测试**：纯逻辑写进 `test/run-tests.js`，云函数写进 `test/run-cloud-tests.js`，页面交互写进 `test/run-page-tests.js`；确认它先失败，再写实现让它通过。
2. **逻辑放在 `utils/`**：页面只做展示与调用，规则都写成可在 Node 里测的纯函数；页面统一从 `utils/context.js` 的 `scope()` 取数，家长端才能自动切到孩子数据。
3. **改了共享文件**（`utils/tasks.js`、`date.js`、`calendar-config.js`、`history-merge.js`、`cheer.js`、`week-brief.js`、`subjects.js`）要跑 `node scripts/sync-cloud-libs.js`，并在变更日志里注明需要重新上传哪个云函数。
4. **提交前跑 `node scripts/run-all.js`**，全部通过再提交（含代码包体积：新增非小程序目录要加进 `project.config.json` 的 `packOptions.ignore`）；推送后 CI 会在 Node 18 / 22、UTC 与北京时间下再跑一遍。
5. **发版时同步三处版本号**：`CHANGELOG.md`（新增一节，写清新增 / 修复 / 部署提示）、本 README 顶部的「当前功能版本」、`pages/profile/profile.js` 的 `APP_VERSION`（「我的」页底部显示）。
6. 涉及文档的改动同时更新 `docs/` 下对应文件，保持文档与代码一致。

## 技术说明

- 客户端采用纯原生小程序框架，无第三方 UI 依赖，使用 emoji 图标；云函数部署需要云端安装 `wx-server-sdk` 等各函数声明的依赖
- 核心逻辑全部收敛在 `utils/`（CommonJS），与页面解耦，因此可以脱离微信环境用 Node 做单元测试（含同步引擎的增量 / 冲突合并测试）；需要在客户端与云函数两边运行的逻辑放在无依赖的共享文件里，由 `scripts/sync-cloud-libs.js` 复制，测试会校验两边一致
- **本地优先（offline-first）**：读写永远走本地，云端是异步备份与跨设备通道；未配置云环境时全部云调用静默降级，UI 不出现不可用状态
- **数据作用域**：页面统一从 `utils/context.js` 的 `scope()` 取数——孩子端读本机，家长端读云端拉下来的孩子数据缓存（只读）
- **同步协议**（按数据形态选择合并规则）：
  - 打卡记录按 `id = date#taskId` 幂等，删除用墓碑（`deleted: true`）双向传播，冲突按 `updatedAt` 新者胜；增量游标以云函数返回的服务器时间为上限，防设备时钟漂移丢数据
  - 勋章只增不删，取并集
  - 资料、任务覆盖（`users.taskOverrides`）、奖励小铺（`users.shop`）、错题本（`users.wrongBook`）会被原地修改，整体按时间戳**新者胜**；写入时间戳严格递增（同毫秒连续操作也生效）
  - 口算会话与小卷历史是只追加列表，按完成时间 `at` **取并集**（`users.practice`）；复习日志每天一条，按日期合并、同日取次数多的一份；每周小目标按周合并，已达成的优先（奖励只算一次）、否则后设置的胜
- **一键清空**：先调 `sync` 云函数的 `reset` 清云端（打卡、勋章、同步字段、收到的留言；保留用户档案、提醒配额与家人绑定），成功后才清本机，避免"本机清了、云端数据又同步回来"
- 星星口径：总星数 = Σ任务星级 + 每日全必做加成 1 星（补卡日除外）+ Σ已获勋章奖励星 + 达成的周目标 × 5；全量动态计算，不冗余存储
- 订阅消息采用**配额模式**：用户每次授权累计 1 次可发送额度（上限 3），定时任务 / 里程碑触发时消费额度，43101（未订阅）自动清零
- **云函数安全**：openid 一律取自调用上下文，绝不信任前端传入；推送的记录只存白名单字段（不接受客户端的 openid / _id / 额外字段），备注、数值、星级限长限范围，未来时间戳按服务器时间封顶（防止伪造很久以后的时间永久压住正常编辑），单次最多 500 条、整体对象有字节上限；邀请码猜错 5 次后 15 分钟内不能再试；孩子可随时「更换邀请码」解除全部家长；家长端只读孩子数据、留言不回传对方 openid；家长留言的自定义文字经 `security.msgSecCheck`，结果非通过或审核不可用时拒绝发送（读者是孩子）
