# 天天小达人 🌟

> 小学生 1-5 年级每日学习 / 运动 / 娱乐打卡微信小程序（上海小学版）
> 语文 · 数学 · 英语 + 跳绳户外 + 非屏幕娱乐，任务按年级自动生成，坚持看得见。
> v0.2.0：新增云开发同步、家人绑定（家长只读视图）、每日提醒与里程碑订阅消息。

## 功能一览

- **每日清单自动生成**：按年级（1-5）+ 日期确定性生成，上学日 4 项必做（语数英 + 跳绳），周末户外升级必做；古诗/单词/日记等按星期轮换
- **假期模式**：内置上海校历，寒暑假自动切换模板（假期作业必做、阅读与户外加量、口算减量、取消整理书包）
- **上海对齐**：沪教版课程语境、"双减"（低年级无书面任务）、近视防控（户外/屏幕限时+家长确认）、睡眠管理、跳绳体测项目
- **打卡闭环**：数值输入 + 星级自评（1-3⭐）+ 一句话记录 + 取消打卡；屏幕时间需家长确认
- **激励体系**：星星、5 级称号、12 枚勋章、连续打卡（今天未打不打断连击）
- **回顾**：月历热力图（达成/有打卡/未打卡）、单日明细、月度统计、本周各板块分布
- **数据自主**：纯本地存储不上传，支持 JSON 导出备份与一键清空

## 快速开始（微信开发者工具）

1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（Stable 版）
2. 打开工具 → 导入项目 → 选择本目录 `tiantian-daka`
3. AppID 选择 **"测试号"**（`project.config.json` 已预置 `touristappid`，正式发布时替换为自己的 AppID）
4. 编译运行：首次进入引导页设置年级昵称，即可开始打卡
5. 运行单元测试（无需任何依赖）：

```bash
node test/run-tests.js
```

## 云开发接入指南（家人绑定 / 提醒 / 多设备同步）

不接入云开发，小程序以**纯本地模式**完整运行（打卡、激励、日历全部可用）。接入后自动获得：

- **多设备同步**：打卡数据加密存云，换设备不丢
- **家人绑定**：孩子生成 6 位邀请码 → 家长输入绑定 → 家长端首页只读查看孩子进度；孩子达成勋章/里程碑时微信通知家长
- **每日提醒**：每天 20:00（可在云函数调整），未完成全部任务时发订阅消息

步骤（约 15 分钟）：

0. 前置：**测试号（touristappid）不支持云开发**——需在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册自己的小程序（个人主体免费），拿到 AppID 并替换 `project.config.json` 中的 `appid`；本机若未装开发者工具，先[下载安装](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)并扫码登录
1. 开通：开发者工具 → 云开发 → 开通，创建环境，复制**环境 ID**
2. 配置环境 ID：编辑 `utils/cloud.js` 顶部 `CLOUD_ENV`
3. 部署函数：右键 `cloudfunctions/` 下 5 个函数（login / sync / family / remind / dailyRemind）→「上传并部署：云端安装依赖」
4. 建索引（控制台 → 数据库）：`checkins` 加 `(openid asc, updatedAt asc)`、`(openid asc, date asc)` 组合索引
5. 申请模板：mp.weixin.qq.com → 订阅消息 → 选用两个"打卡提醒"类模板（各含两个"事物"字段）→ 把模板 ID 分别填入 `cloudfunctions/remind/config.js`、`cloudfunctions/family/config.js`（字段名不同则同步修改对应 `index.js` 的 `data` 字段）
6. 修改了 `utils/tasks.js` 后运行 `node scripts/sync-cloud-libs.js` 同步到 `cloudfunctions/dailyRemind/lib/` 并重新上传该函数
7. 真机验证：孩子端「我的 → 家人绑定」显示邀请码 → 家长手机输入绑定；点「开启提醒」授权一次后，次日 20:00 应收到消息

## 技术说明

- 纯原生小程序框架，**零第三方依赖、零图片资源**（emoji 图标体系），可直接编译
- 核心逻辑全部收敛在 `utils/`（CommonJS），与页面解耦，因此可以脱离微信环境用 Node 做单元测试（含同步引擎的增量/冲突合并测试）
- **本地优先（offline-first）**：读写永远走本地，云端是异步备份与跨设备通道；未配置云环境时全部云调用静默降级，UI 不出现不可用状态
- 同步协议：记录按 `id = date#taskId` 幂等；删除用墓碑（`deleted: true`）双向传播；冲突按 `updatedAt` 新者胜；勋章只增并集
- 订阅消息采用**配额模式**：用户每次授权累计 1 次可发送额度（上限 3），定时任务/里程碑触发时消费额度，43101（未订阅）自动清零
- 云函数安全：openid 一律取自调用上下文，绝不信任前端传入
