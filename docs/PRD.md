# 天天小达人 · 产品需求文档（PRD）

> 小学生 1-5 年级每日学习 / 运动 / 娱乐打卡小程序（上海小学版）
> 版本 0.22.0 · 2026-10 · 本地功能完整；云端能力已编码、待开通云环境验证

---

## 1. 背景与问题

家长普遍面临三个痛点：

1. **"每天该做什么"不清晰** —— 各科要求散落在老师通知、班级群里，缺乏一份按年级适配的每日清单。
2. **孩子坚持难** —— 口头督促容易变成亲子冲突，孩子缺少即时、可视的正反馈。
3. **屏幕失控** —— 娱乐时间没有结构，动画/游戏挤掉运动和阅读。

同时，上海小学有一套明确的政策与课程语境，产品内容必须"贴合上海"，而不是通用打卡：

| 政策 / 语境 | 对产品的影响 |
| --- | --- |
| "双减"：1-2 年级不布置书面回家作业 | 低年级（1-2）任务以朗读、口算（口头/卡片）、跟读、阅读为主，不设书面作业类任务 |
| 每天体育锻炼 1 小时 + 校外锻炼 | 运动为每日必做板块，默认任务为跳绳 |
| 跳绳是上海小学生体质健康测试重点项目（亦为体育中考项目之一） | 跳绳按年级段量化目标：1-2 年级 100 个/天、3-4 年级 300 个/天、5 年级 400 个/天 |
| 近视防控："目浴阳光"、每天户外 2 小时 | 娱乐板块优先非屏幕（兴趣、桌游、户外）；屏幕时间默认 ≤15 分钟且需家长确认；周末户外活动升级为必做 |
| 睡眠管理：小学生每天 10 小时 | 习惯板块含"早点睡觉（21:20 前上床）" |
| 等第制评价（低中年级不以分数排名） | 激励反馈用星星/称号/勋章，小卷只给等第（优秀/良好/合格/继续加油），不做排行榜 |
| 沪教版教材（数学沪教版、英语牛津上海版） | 任务文案、口算分级、小卷题库与跟读内容均对齐上海 2024 新教材 |

## 2. 产品定位

**一句话**：给上海小学生的一张"每天照着做就行"的打卡清单，孩子自己打、家长少催促，坚持看得见。

- **主用户**：上海小学 1-5 年级学生（操作者）
- **辅用户**：家长 —— 在孩子手机上做初始设置、任务/奖品管理、屏幕时间与补卡确认；开通云开发后用自己的微信绑定孩子，只读查看进度、周报与错题，并发鼓励留言
- **不做的事**：不做社交/排行（避免比较焦虑；留言只在绑定的家人之间）、不做拍照上传（隐私）、不做错题拍照识别等重功能、孩子侧不开放自由打字（回复只用固定表情）

### 3.5 远期（依赖前置条件）

- **班级打卡圈 / 教师点评**：⛔ 硬依赖——微信云环境开通 + 班级/教师组织关系 + 未成年人社交数据合规设计（个保法：不满 14 周岁需监护人同意），须在云环境上线并与老师侧确认流程后启动
- **英语发音评测**（在跟读教室基础上加打分）：需接入付费语音评测服务（腾讯云 SoEd / 讯飞等）+ 正式 AppID
- **家长周报推送**：周报页面已实现；订阅消息推送需新申请模板
- **一年级下册内容**：口算 / 小卷 / 跟读题库随学期进度扩充，需确认教材版本与单元

## 4. 每日任务生成规则（概要）

- 生成是**确定性**的：`generateDailyTasks(grade, date)` 同一输入永远同一清单（家长任务覆盖会参与生成）。
- 上学日必做 4 项：语文朗读 / 口算 / 英语跟读 / 跳绳；周末必做改为：朗读 / 口算 / 英语跟读 / **户外活动**；假期必做改为：假期作业 / 课外阅读 / 口算 / 户外活动。
- 每周轮换：古诗古文（一三五）、单词打卡（二四）、练字（低年级二四）、日记/周记、思维挑战、知识梳理（周六）等。
- 完整任务库（21 个学期任务 + 假期作业）与各年级段目标值见 [content-tasks.md](content-tasks.md)。

## 5. 激励体系

| 元素 | 规则 |
| --- | --- |
| 任务星 | 每完成一项 1 ⭐，自评加成最高 3 ⭐/项；补打卡固定 1 ⭐ |
| 日目标星 | 当日全部必做完成 +1 ⭐（补卡的那天不计） |
| 勋章加成星 | 里程碑勋章附带奖励星（如"一周坚持王"+5 ⭐） |
| 周目标星 | 孩子自选的每周小目标达成 +5 ⭐（每周一个，达成后锁定） |
| 称号 | 见习(0)→铜星(50)→银星(150)→金星(350)→传奇(700)，按总星星 |
| 勋章 | 18 枚：打卡类（首次/完美一天/连击 7-30-100/全勤周/朗读者/口算/跳绳/书虫/阳光/小作家）+ 练习类（兑换初体验/小卷爱好者/满分小卷/背诗小能手/口算满分王/错题克星） |
| 积分 | 累计获得的每颗 ⭐ 等额变为积分（含日目标星、勋章奖励星与周目标星）；**花积分不减星星和称号**。家长在「奖品管理」上架奖品/零食并定价，孩子在「奖励小铺」兑换，兑换后由家长兑现（可撤销退分） |
| 连击 | 有打卡记录的连续天数；今天还没打卡不打断；补打卡能接上 |

设计原则：**只和昨天的自己比**，没有排行榜、没有他人可见。

## 6. 隐私与合规

- **默认纯本地**：未开通云开发时，所有数据只存本机（wx storage），不上传任何信息；「我的」页提供导出、导入与一键清空。
- **开通云开发后**：最小化采集——昵称、头像 emoji、年级、学校（选填）、打卡与练习记录；不采集真实姓名、照片、位置。跟读录音始终只存本机。数据仅本人与绑定的家人可见；云函数一律以调用上下文的 openid 鉴权，不信任前端传入。
- **家长留言**：只在绑定的家人之间；自定义文字经微信内容安全检查（`security.msgSecCheck`），检查不通过或不可用时拒绝发送；孩子回复只能用固定表情；每位家长每天最多 10 条。
- **一键清空**：开通云开发后同时清空云端（打卡、勋章、同步数据、收到的留言），先清云端、成功后才清本机。
- 屏幕娱乐类任务内置家长确认与时长上限引导（教育部电子产品使用指引：单次 ≤15 分钟）。
