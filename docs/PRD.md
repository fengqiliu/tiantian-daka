# 天天小达人 · 产品需求文档（PRD）

> 小学生 1-5 年级每日学习 / 运动 / 娱乐打卡小程序（上海小学版）
> 版本 0.3.0 · 2026-10 · 假期模式已实现

---

## 1. 背景与问题

家长普遍面临三个痛点：

1. **"每天该做什么"不清晰** —— 各科要求散落在老师通知、班级群里，缺乏一份按年级适配的每日清单。
2. **孩子坚持难** —— 口头督促容易变成亲子冲突，孩子缺少即时、可视的正反馈。
3. **屏幕失控** —— 娱乐时间没有结构，动画/游戏挤掉运动和阅读。

同时，上海小学有一套明确的政策与课程语境，产品内容必须"贴合上海"，而不是通用打卡：

| 政策 / 语境 | 对产品的影响 |
| --- | --- |
| "双减"：1-2 年级不布置书面回家作业 | 低年级（1-2）任务以朗读、口算（口头/卡片）、跟读、阅读为主，不设书面作业类任务 |
| 每天体育锻炼 1 小时 + 校外锻炼 | 运动为每日必做板块，默认任务为跳绳 |
| 跳绳是上海小学生体质健康测试重点项目（亦为体育中考项目之一） | 跳绳按年级段量化目标：1-2 年级 100 个/天、3-4 年级 300 个/天、5 年级 400 个/天 |
| 近视防控："目浴阳光"、每天户外 2 小时 | 娱乐板块优先非屏幕（兴趣、桌游、户外）；屏幕时间默认 ≤15 分钟且需家长确认；周末户外活动升级为必做 |
| 睡眠管理：小学生每天 10 小时 | 习惯板块含"早点睡觉（21:20 前上床）" |
| 等第制评价（低中年级不以分数排名） | 激励反馈用星星/称号/勋章，不用分数、不做排行榜 |
| 沪教版教材（数学沪教版、英语牛津上海版） | 任务文案明确指向沪教版口算、牛津上海版课文跟读 |

## 2. 产品定位

**一句话**：给上海小学生的一张"每天照着做就行"的打卡清单，孩子自己打、家长少催促，坚持看得见。

- **主用户**：上海小学 1-5 年级学生（操作者）
- **辅用户**：家长（初始设置、屏幕时间确认、周末陪同户外）
- **不做的事**（MVP 边界）：不做社交/排行（避免比较焦虑）、不做拍照上传（隐私）、不做错题拍照识别等重功能

## 3. 核心功能清单

### P0（MVP，本仓库已实现）

| 模块 | 功能 |
| --- | --- |
| 引导 | 首次启动三步引导：欢迎 → 选年级（1-5）→ 昵称/头像/学校（选填） |
| 今日打卡 | 按年级+日期自动生成任务清单，分语文/数学/英语/运动/娱乐/习惯六组；4 项"必做"达成当日目标 |
| 任务打卡 | 数值输入（步进器+快捷档）、3 档星级自评（加油/不错/超棒 → 1-3 ⭐）、一句话记录、取消打卡 |
| 家长确认 | "屏幕时间"任务保存前弹家长确认 |
| 日历 | 月历打卡热力图（绿=达成 / 黄=有打卡 / 灰=未打卡）、单日明细、月度统计 |
| 成长 | 星星总数与称号进度（见习→铜→银→金→传奇）、连续打卡、本周各板块分布、12 枚勋章墙 |
| 我的 | 资料编辑（改年级后任务自动变化）、数据导出（JSON 剪贴板备份）、双确认清空 |

## 4. 每日任务生成规则（概要）

- 生成是**确定性**的：`generateDailyTasks(grade, date)` 同一输入永远同一清单。
- 上学日必做 4 项：语文朗读 / 口算 / 英语跟读 / 跳绳；周末必做改为：朗读 / 口算 / 英语跟读 / **户外活动**。
- 每周轮换：古诗古文（一三五）、单词打卡（二四）、练字（低年级二四）、日记/周记、思维挑战、知识梳理（周六）等。
- 完整任务库（21 个任务定义）与各年级段目标值见 [content-tasks.md](content-tasks.md)。

## 5. 激励体系

| 元素 | 规则 |
| --- | --- |
| 任务星 | 每完成一项 1 ⭐，自评加成最高 3 ⭐/项 |
| 日目标星 | 当日全部必做完成 +1 ⭐ |
| 勋章加成星 | 里程碑勋章附带奖励星（如"一周坚持王"+5 ⭐） |
| 称号 | 见习(0)→铜星(50)→银星(150)→金星(350)→传奇(700)，按总星星 |
| 勋章 | 12 枚：首次打卡/完美一天/连击 7-30-100/全勤周/朗读者/口算/跳绳/书虫/阳光/小作家 |

设计原则：**只和昨天的自己比**，没有排行榜、没有他人可见。

## 6. 隐私与合规

- MVP 所有数据存储在本机（wx storage），**不采集、不上传任何个人信息**；"我的"页提供一键导出与清空。
- 屏幕娱乐类任务内置家长确认与时长上限引导（教育部电子产品使用指引：单次 ≤15 分钟）。
- 未来接入云开发时，最小化采集（仅昵称/年级/打卡记录），不采集真实姓名、照片、位置。
