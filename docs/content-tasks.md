## 2. 每日清单生成规则

```
generateDailyTasks(grade, date)   // 确定性：同 (年级, 日期) 永远同一份清单
```

**上学日（周一~周五）**

- 必做 4 项：课文朗读、口算天天练、英语跟读、跳绳
- 固定自选：课外阅读、兴趣时间、户外活动、屏幕时间、整理书包、早点睡觉
- 按星期轮换：
  - 周一/三/五：+ 古诗古文背诵
  - 周二/四：low + 练字；mid + 单词打卡 + 看图说话 + 体能组合；high + 单词打卡 + 体能组合
  - 周三/五：high + 小日记

**周末（周六/周日）**

- 必做 4 项：课文朗读、口算、英语跟读、**户外活动（60/90 分钟）** —— 户外升级为必做，呼应近视防控
- 固定自选：课外阅读（加量）、兴趣时间、亲子桌游、球类运动、屏幕时间、家务小帮手、早点睡觉
- mid/high 追加：思维挑战、英语绘本阅读；周六 + 知识梳理；周日 + 周记

每日清单约 7-11 项，其中必做恒为 4 项 —— 目标清晰、不超载。

## 3. 政策与课程依据

| 依据 | 落点 |
| --- | --- |
| "双减"意见（2021）：1-2 年级不布置书面家庭作业 | low 段无书面类任务；口算提供口头形式说明 |
| 五项管理·睡眠：小学生 10 小时 | habit_sleep 文案 |
| 五项管理·体质/教育部每天锻炼要求 | 运动每日必做；跳绳按上海体测/体育中考常考项目设置 |
| 近视防控：户外活动"目浴阳光" | pe_outdoor 每日任务、周末必做；娱乐非屏幕优先 |
| 电子产品使用：单次 ≤15 分钟 | fun_screen 目标值与家长确认 |
| 沪教版数学、牛津上海版英语、统编语文 | 各任务文案指向对应教材内容 |
| 上海等第制评价（低中年级不排名） | 无分数、无排行榜，激励用星星/称号/勋章 |

## 4. 扩展方式

新增任务只需在 `utils/tasks.js` 的 `DEFS` 中加一条定义、并在 `generateDailyTasks` 的对应分支加入清单；页面、统计、勋章逻辑无需改动（勋章如需挂钩新任务，在 `utils/badges.js` 增加一条定义即可）。
