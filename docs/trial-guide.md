# 试用指南（Lucy 版 · 7 天观察计划）

> 目标：让真机使用告诉我们"任务量合不合适、内容难不难"，比任何新功能都有价值。
> 本指南假设当前用**测试号**运行（家人绑定/提醒/同步暂不可用，不影响打卡与练习）。

## Day 0 · 准备（约 10 分钟）

1. 微信开发者工具导入项目 → 编译通过后点工具栏「预览」→ 用**孩子日常用的那台手机**的微信扫码打开
2. 首次引导：身份选「我是孩子」→ 年级选 **1** → 昵称（Lucy）→ 选头像 → 学校选填
3. ⚠️ **重要**：打卡数据存在本机，请固定用 Lucy 的设备作为主设备（换手机数据不跟走；开通云环境后才会多设备同步）
4. 建议顺手做的两个设置：「我的 → 任务管理」先不动，跑 2-3 天再调

## 每天怎么用（放学说辞）

- **放学后**：打开小程序 → 今日清单从上往下做。朗读、口算可以配合纸质作业做完再打卡；口算也可以直接点任务进「🧮 口算挑战」在 App 里做
- **英语**：跟读任务点进「🎧 跟读教室」，逐句录音，第一次会请求麦克风权限（允许）
- **周末**：清单会变（户外变必做、作业消失）；可以加练一份「📝 每周一卷」（成长页进入）
- **打卡后**：看星星、勋章和连击——正反馈是孩子坚持的核心

## 每天观察清单（家长 1 分钟）

| 观察点 | 记什么 |
| --- | --- |
| 任务量 | 今天清单太满还是太松？哪项没做完？原因（不想做 / 不会 / 没时间）？ |
| 口算 | 「口算挑战」大概正确率？错题集中在哪种（进位退位 / 填空）？ |
| 跟读 | 愿不愿意开口？录了几句？句子会不会太长？ |
| 主动性 | 是自己打开还是被催？有没有主动看星星/勋章？ |
| 时间 | 全部做完大约花多久？什么时候做的（放学后 / 饭后 / 睡前）？ |

## 调整手册（我的 → 任务管理）

| 情况 | 建议动作 |
| --- | --- |
| 某项连续 2-3 天做不完 | 该任务目标值减 20-30%（如跳绳 100→70 个） |
| 清单整体太满 | 优先减"自选"项目标，必做 4 项保持（结构由系统锁定） |
| 做得太快觉得不够 | 目标值加量，或「添加自定义任务」（如 练钢琴 20 分钟 🎹、围棋 15 分钟 ⭐） |
| 某项孩子明显抵触 | 换形式（纸质→App 内 / 口头→朗读给家长听），实在不行几天后再上 |

## 第 7 天 · 把这些发给我

1. 打卡日历页截图（能看到哪些天达成）
2. 口算挑战和每周一卷的大概正确率
3. 孩子最喜欢 / 最抗拒的任务各一个
4. 你在任务管理里做过的调整

我会据此把默认任务参数、题目难度和内容量调到"踮踮脚够得着"的状态。

## 边界与提醒

- 测试号模式：家人绑定 / 每日提醒 / 多设备同步不可用（需注册 AppID + 开通云环境，见 README）
- 跟读录音仅保存在本机、自动保留最近 7 天，不会上传
- 数据随时可导出：「我的 → 数据 → 导出数据」
